# Sound Files for Word Memory Game

This game uses three sound effect files that should be placed in this directory:

1. `flip.mp3` - Card flip sound
2. `match.mp3` - Sound played when a match is found
3. `error.mp3` - Sound played when a mismatch occurs

You can download free sound effects from these websites:

- https://mixkit.co/free-sound-effects/
- https://freesound.org/
- https://www.zapsplat.com/

Recommended sounds (all royalty-free):

- For flip.mp3: A short "click" or "card flip" sound
- For match.mp3: A short "success" or "achievement" sound
- For error.mp3: A short "error" or "wrong answer" sound

Note: Make sure the files are named exactly as specified above and placed in the public directory.
