# Word Memory Game

A language learning memory matching game built with React and Next.js. Match English words with their French equivalents in a beautiful, responsive interface.

## Features

- Interactive matching game with English and French vocabulary
- Animated card flips with visual feedback
- Score tracking based on moves and time
- Confetti celebration animations for matches
- Responsive design that works on desktop and mobile
- GRADE button to check your progress

## Live Demo

Check out the live demo: [Word Memory Game](https://memory-game-five-orpin.vercel.app/)

## Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/hieunguyen098/memory-game.git
cd memory
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.

## How to Play

1. Click the "GO!" button to start the game
2. You'll briefly see all cards flipped - try to memorize their positions!
3. Cards will flip back, and you need to find matching pairs
4. Click on any card to flip it, then try to find its match
5. Match all pairs to complete the game
6. Click the "GRADE" button at any time to see your current score
7. Click "GO!" to reset and continue playing
8. Your final score will also be shown when you complete the game
